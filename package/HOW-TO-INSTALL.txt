GATHER TWEAKS - HOW TO INSTALL
===============================

Requires BepInEx for Valheim.

MANUAL
1. Extract this zip.
2. Open the "plugins" folder from the zip.
3. Copy the "GatherTweaks" folder into:
       Valheim\BepInEx\plugins\

   Result:
       Valheim\BepInEx\plugins\GatherTweaks\GatherTweaks.dll

4. Launch the game.

R2MODMAN / THUNDERSTORE MOD MANAGER
Settings > Import local mod > pick this .zip (don't extract it).

UPDATING
Delete the old GatherTweaks folder first.

Config: press F1 in game (Configuration Manager) or edit
Valheim\BepInEx\config\felih.GatherTweaks.cfg. See README.md.
